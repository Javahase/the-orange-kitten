# The Orange Kitten

This repository contains the game "The Orange Kitten" and log files from the studies that have been conducted.

Important: 
- The LLM-List from ChatAI that is currently in the source code does not match with the actual list, some LLMs are missing or have been removed.
- To be able to play the game, you must insert an API-Key valid for the ChatAI-services into `Assets/Resources/Secrets/api_key.txt`
- If you want to include your own LLM from your own API, refer to the `LLMService`/`InsightService`-Documentation and change the scripts within the `MainStage` scene to the respective new services.
